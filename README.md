# Dibrugarh University BCA-CDOE

A modern digital study portal designed for BCA students of Dibrugarh University's Centre for Distance and Open Education (CDOE).

🌐 **Live Website:** https://stillfixing.github.io/Project-BCA/

## 📖 About the Project

This website provides BCA students with a simple and accessible place to find academic resources and information.

The portal brings together:

- 📘 Study Notes
- 📝 Previous Year Questions (PYQs)
- 📚 BCA Syllabus
- 👨‍🏫 Faculty Information
- 🖼️ Campus Gallery
- ℹ️ Information about the BCA program

The goal is to make important academic resources easier for students to access in one place.

## 🎓 BCA Program

The BCA program is a 3-year undergraduate degree consisting of 6 semesters.

### Key Areas

- Programming
- Database Management Systems
- Web Development
- Computer Networking
- Software Engineering
- Practical Projects and Lab Work
